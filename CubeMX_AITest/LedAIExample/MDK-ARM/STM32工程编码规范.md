## 章节骨架

### 1. 工程架构与分层规范
三层分层架构（Device / Operation / Task），只允许上层调用下层，禁止反向依赖。

### 2. 文件规范
`.c`/`.h` 同名成对，头文件必须带 include guard，统一 `_XXX_H_` 格式。

### 3. 命名规范
类型加 `Tdf` 后缀；变量用匈牙利前缀（`v/st/em/ul/us/uc/pst/a/s_`）；枚举成员显式赋初值；宏全大写下划线分词。

### 4. 注释规范
接口函数统一 `///` Doxygen 注释块（`@brief`/`@param`/`@note`，中文）；关键逻辑上方加 `//` 步骤注释；结构体成员注释行尾对齐。

### 5. 代码格式规范
Tab 缩进；结构体声明三列对齐；大括号独占一行；`switch` 必须带 `default`。

### 6. 数据组织与接口设计规范
静态参数与运行参数分离；设备参数全局数组集中管理、const 指针只读访问；"零初始化 + 逐项赋值 + memcpy"初始化；状态与电平解耦。

### 7. RTOS 任务规范
任务体固定为"初始化 + `while(1)` + `vTaskDelay`"骨架，周期动作聚合为单个 `vXxxExecuteAll` 接口。

### 8. 已知不一致项
登记现有代码与规范的偏差点及修复状态，作为后续重构清单。

## 扩展指引

- **新增章节**：在 `编码规范/` 目录下新建 `序号_章节名.md`（两位数字前缀，可跳号预留），并在本文件"规范总览"表与"章节骨架"中登记一行摘要。
- **新增模块**：如 Button、Display 等，参照 Device / Operation / Task 三层模式扩展，适用本规范全部章节。
- **修改规范**：只改对应子文件；若涉及章节增删或结构调整，同步更新本主索引。
