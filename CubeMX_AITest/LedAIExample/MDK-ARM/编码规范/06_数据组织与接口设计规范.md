## 6.1 静态参数 / 运行参数分离

设备参数按"是否运行时变化"拆分为两个结构体，再聚合为设备参数总结构：

```c
typedef struct
{
    stLedRunningParamTdf stRunningParam;    // 运行时动态变化
    stLedStaticParamTdf  stStaticParam;     // 初始化后不变
} stLedDeviceParamTdf;
```

- **静态参数**：GPIO 端口、引脚、点亮电平等，仅初始化时写入一次（`vLedDeviceInit`）。
- **运行参数**：当前状态、模式、计数器、阈值等，运行中持续更新。

## 6.2 设备参数集中管理

- 所有设备参数以 **全局数组** 形式定义在 Device 层 `.c` 文件中，以设备编号枚举作为下标：

```c
stLedDeviceParamTdf astLedDeviceParam[LED_DEV_NUM];
```

- 外部模块读取参数必须通过只读访问接口，返回 const 指针：

```c
const stLedDeviceParamTdf *c_pstGetLedDeviceParam(emLedDevNumTdf emDevNum);
```

## 6.3 初始化方式

- 采用"局部零初始化结构体 + 逐项赋值 + 整体拷贝"模式：

```c
stLedStaticParamTdf stInit = {0};

stInit.pstGpioBase = GPIOC;
stInit.usGpioPin   = GPIO_PIN_13;
stInit.emOnLevel   = emLedOnLevel_Low;

vLedDeviceInit(&stInit, emLedDevNum0);
```

- 结构体拷贝统一使用 `memcpy`，长度写作 `sizeof(类型) / sizeof(uint8_t)`。

## 6.4 状态更新闭环

改变 LED 状态的接口（`vLedOn` / `vLedOFF` / `vLedToggle`）遵循固定两步模式：

1. 更新运行参数中的状态枚举 `emCurrentStatus`；
2. 调用 `vLedUpdatePinLevel()` 统一换算电平并写 GPIO。

即 **状态与电平解耦**：点亮电平（高/低有效）由静态参数 `emOnLevel` 决定，业务层只操作逻辑状态。
