# 03 命名规范

[← 返回主索引](../STM32工程编码规范.md)

---

## 3.1 类型定义（`Tdf` 后缀）

所有自定义类型以 `Tdf`（Type Define）结尾，并按类别加前缀：

| 前缀 | 含义 | 示例 |
|------|------|------|
| `st` | 结构体 | `stLedStaticParamTdf`、`stLedRunningParamTdf` |
| `em` | 枚举 | `emLedModeTdf`、`emLedStatusTdf` |
| `un` | 联合体 | （预留约定） |

## 3.2 枚举命名

- 枚举类型：`em + 模块 + 含义 + Tdf`，如 `emLedOnLevelTdf`。
- 枚举成员：`em + 模块 + 含义_值`，如 `emLedMode_Blink`、`emLedOnLevel_Low`。
- **首个成员显式赋 0**，其余递增：

```c
typedef enum
{
    emLedMode_Static = 0,
    emLedMode_Blink,
    emLedMode_Breath,
} emLedModeTdf;
```

- 设备编号统一使用枚举管理（`emLedDevNum0 ~ emLedDevNum8`），禁止在代码中出现魔法数字索引。

## 3.3 函数命名（动作前缀 + 模块 + 功能）

返回值/行为通过前缀体现：

| 前缀 | 含义 | 示例 |
|------|------|------|
| `v` | 返回 void | `vLedOn()`、`vLedDeviceInit()` |
| `c_pst` | 返回 const 结构体指针 | `c_pstGetLedDeviceParam()` |

命名模式：`前缀 + 模块名 + 动作`，如 `vLedDevicePeriodExecute`、`vLedToggle`。

- 参数中带设备编号的接口，设备号参数统一命名 `emDevNum`，类型为 `emLedDevNumTdf`。

## 3.4 变量命名（匈牙利前缀）

| 前缀 | 类型 | 示例 |
|------|------|------|
| `ul` | `uint32_t` | `ulCurrentCount`、`ulBreathPeriod` |
| `us` | `uint16_t` | `usGpioPin` |
| `uc` | `uint8_t` | `ucOutput` |
| `em` | 枚举变量 | `emCurrentStatus`、`emOnLevel` |
| `st` | 结构体变量 | `stInit`、`stRunningParam` |
| `pst` | 结构体指针 | `pstGpioBase`、`pstInit` |
| `a` | 数组 | `astLedDeviceParam[]` |
| `s_` | 静态变量 | `s_ulBreathCount` |
| `c_` | const 限定 | `c_pstGetLedDeviceParam` |

前缀可叠加：`ast` = 结构体数组，`s_ul` = 静态 uint32_t。

## 3.5 宏定义

- 全大写 + 下划线分词：`LED_DEV_NUM`、`PI`、`TRUE`、`FALSE`。
- 数量类宏用于数组维度与循环边界：`#define LED_DEV_NUM 9`。
- 设备别名宏映射到设备编号枚举，提高可读性：

```c
#define LED_BOARD   emLedDevNum0
#define LED1        emLedDevNum1
```

- 芯片 HAL 头文件名通过配置宏间接引用：`STM32_IC_HAL`（`Project_Config.h`）。
