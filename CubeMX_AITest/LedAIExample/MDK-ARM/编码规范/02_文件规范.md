## 2.1 文件命名

- 同一模块的 `.c` / `.h` 文件同名。
- 模块文件命名格式：`功能_层级.c/h`（如 `Led_Operation.c`、`Led_Task.c`）或 `功能Device.c/h`（如 `LedDevice.c`）。
- 头文件中使用 `#include` 只引入本模块直接依赖的头文件。

## 2.2 头文件保护

- 所有头文件必须带 include guard，格式为下划线包裹的全大写文件名：

```c
#ifndef _LED_TASK_H_
#define _LED_TASK_H_

/* ... */

#endif
```

> 现状说明：工程中 include guard 已统一为 `_XXX_H_`（单下划线）风格，**新文件必须采用 `_XXX_H_`**。
