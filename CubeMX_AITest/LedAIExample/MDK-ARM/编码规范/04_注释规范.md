## 4.1 函数注释（Doxygen 风格）

接口函数统一使用 `///` Doxygen 注释块，包含 `@brief` / `@param` / `@note` 三个标签，注释内容为中文：

```c
/// @brief              LED设备初始化
///
/// @param  pstInit     :   初始化参数结构体的首地址
/// @param  emDevNum    :   设备编号
/// @note
void vLedDeviceInit(stLedStaticParamTdf *pstInit, emLedDevNumTdf emDevNum);
```

- `@param` 后参数名与说明之间用 `:` 分隔，说明列纵向对齐。
- 无参数、无注意事项时标签保留、内容留空。

## 4.2 行内注释

- 关键逻辑步骤使用 `// 中文说明`，置于代码上方一行，不置于行尾：

```c
//设置当前状态
astLedDeviceParam[emDevNum].stRunningParam.emCurrentStatus = emLedStatus_ON;

//根据当前状态更新输出引脚电平
vLedUpdatePinLevel(emDevNum);
```

## 4.3 结构体成员注释

- 成员注释写在成员行尾，使用 `//`，多成员时注释列对齐：

```c
typedef struct
{
    GPIO_TypeDef    *pstGpioBase;   // 使用的GPIOx
    uint16_t         usGpioPin;     // 使用的GPIO_PIN_x
    emLedOnLevelTdf  emOnLevel;     // LED点亮时的电平
} stLedStaticParamTdf;
```
