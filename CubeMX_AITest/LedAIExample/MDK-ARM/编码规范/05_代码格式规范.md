# 05 代码格式规范

[← 返回主索引](../STM32工程编码规范.md)

---

- **缩进**：使用 Tab（1 Tab = 4 空格宽度）。
- **声明对齐**：结构体成员的类型、变量名、注释三列纵向对齐（Tab 对齐）。
- **大括号**：函数定义、`switch` 的 `case` 块大括号独占一行。
- **空行**：函数之间空一行；逻辑段落之间用空行分隔。
- **运算符**：赋值、比较运算符两侧留空格。
- **switch 必须带 default 分支**，即使为空也显式写出：

```c
default:
{
    ;
}
```
